# lanaviera.cl

Static site (plain HTML/CSS/JS) for Estancia La Naviera. Hosted on GitHub Pages.

## Images

All photos are in images/, matched one by one to where they sat on the old Wix site and resized for the web
(headers 2200px, page photos 1000-1400px, gallery 1600px with 640px thumbnails ending in -t.jpg).
To swap a photo, replace the file with one of the same name.

## PDFs (already in assets/pdf, compressed from 36-70 MB down to 5-11 MB)

Spanish programmes and the Experiencia Gaucha, English versions of the same four (linked as "English" on Visítanos), and the book.
The 8-day programmes stay near 10 MB because a few CMYK images were left untouched on purpose.
